# Visie 收藏原图批量下载（脚本猫）

在**你平时使用、已经通过 Google 登录 Visie 的 Chrome** 中安装。无需登录 PI 内置浏览器，无需传递密码、1Password 验证码或 Cookie。

## 安装（只做一次）

1. 打开 Chrome 的「脚本猫」扩展，进入脚本管理页面，选择新建普通用户脚本。
2. 用文本编辑器打开同目录的 `visie-shortlist-downloader.user.js`，复制**全部内容**（包括开头的 `==UserScript==` 信息）。
3. 删除新建脚本的默认内容，粘贴并保存，确认脚本启用。
4. 返回 `https://visie.io/shortlists/512` 并刷新。右下角会出现 **Visie 下载**。
5. 若 Chrome 提示必须允许用户脚本，按脚本猫提示在扩展详情启用相应权限；不同 Chrome 版本的开关名称可能不同。

也可以使用脚本猫自带的本地脚本导入功能（若当前版本提供）。不必把源码粘贴到开发者控制台，也不必安装 Node 或 Python。

**从旧版升级到 v1.1.0**：编辑脚本猫中原来的 Visie 脚本，用新文件的全部内容覆盖并保存，然后刷新 Visie。不必另建第二个同名脚本。

## v1.2.0 使用方式（按项目挑选 + 自定义命名）

1. 打开收藏页，点右下角 **Visie 下载**，弹出项目列表。默认**一张都不选**。
2. 点项目卡片＝选中/取消整个项目；点 **选单张** 展开，只勾其中几张。可搜索项目名、品牌、日期。
3. **选未下载**：只选还没下过的图片；**隐藏已下载项目**：列表里只留新项目。脚本在每包 ZIP 发起保存后才记为“已下载”，记录保存在脚本猫里，可在右侧清除。
4. 右侧设置命名：选预设，或在“文件夹名”“文件名”里用字段拼接，例如 `{品牌}_{日期}_{项目}`。点字段按钮会插入到光标处，下方实时预览。文件夹名留空＝所有图片放一层。同名文件自动加 `_2`。
5. 点 **开始下载（N 张）**。命名和下载设置会自动记住。

可用字段：收藏、项目、完整标题、品牌、日期、项目序号、图片序号、总序号、原文件名、尺寸、图片ID。

## 每次下载

1. 在原来的 Chrome 中打开任意 Visie 收藏详情页。
2. 点击右下角 **Visie 下载**，自动读取清单并弹出缩略图选图窗口，无需先滚动页面。
3. 默认全选；可逐张勾选，也可按项目筛选、全选、清空或反选。**筛选本身不改变选择**：只下某项目时，先在“全部项目”清空，再筛选该项目并全选。图片较多时分页显示，翻页不会丢失已选项。
4. 点 **开始下载**，默认自动分包保存 ZIP，不再每包确认。每包最多 50 张，图片数据达到约 64 MiB 提前分包。Chrome 若提示是否允许多个文件下载，请在确认是 Visie 后允许。
5. 等待“处理完成”，查看 Chrome 下载列表确认 ZIP 已保存。解压后，图片按收藏条目/项目分文件夹。

每个 ZIP 也包含 `图片清单.json`（原地址、尺寸及文件对应关系）和 `下载报告.json`（跳过统计及该包的失败项）。中文文件名采用 UTF-8。

- **下载设置**：可选每包 25/50/100 张，或关闭“自动保存 ZIP”改回逐包点击绿色按钮。设置保存在脚本猫中，下次自动恢复；选图清单和账号数据不会持久保存。
- **停止**：中止当前请求，已获取但未保存的图片仍可手动保存。保存后可继续剩余图片。
- **重试失败**：重新尝试失败项，不重复下载成功项；某张失败不会导致整包成功图片丢失。
- **重新保存最近一包**：无需再请求图片即可补存。为限制内存只保留最近一包；更早的包若被浏览器拦截，需要重新选择对应图片下载。
- **导出所选链接**：仅导出当前勾选图片的原始 URL。可能带签名的链接请勿公开分享。
- **重新选图**：开始新的所选下载任务会重置当前任务进度，可能重新下载之前的图片；只想断点继续请使用“继续剩余图片”。
- 任务期间不要关闭或刷新标签页；本版不支持跨刷新断点续传。切换收藏后需重新读取。

## 下载范围与原图含义

- 按收藏页公开前端实际使用的 `props.shortlist.items[].item.media` 读取，不依赖是否滚动到图片。
- 只读取本次收藏中各条目提供的媒体清单；**不会扩展抓取某个项目或摄影师的其他作品**。
- 使用媒体对象的 `url` 原始地址，不把 `_medium.webp` 缩略图猜成 JPG，也不在失败时偷偷降级。
- “原图”是 **Visie 对当前页面提供的源图片文件**，不意味着摄影师的 RAW 文件或平台未公开的更高清版本。
- 跳过视频、文本标题、失效条目；同一图片 URL 在本次清单中只保存一次。未知条目类型和不受支持域名会明确计数提示。
- 支持 JPEG、PNG、WebP、GIF、AVIF、BMP、TIFF；检查文件头，避免把登录页面或错误页面当成图片保存。单张图片超过 64 MiB 会报错，可改用导出的链接单独下载。
- 如果网站返回分页数据或结构与本版不符，脚本会停止并说明原因，不会冒称下载完整。

## 隐私与权限

- 只有主动打开下载面板或点击读取/下载才请求清单及预览；只使用 GET，不添加、删除、改名或分享收藏。
- 收藏页用浏览器的现有登录状态读取。图片请求仅允许 `cdn.visie.io`、`visie.io`、`www.visie.io`。
- CDN 原图请求不携带账号 Cookie。若脚本猫询问是否允许访问上述域名，可核对域名后授权。
- 不读取密码、验证码，不提取或导出 Cookie，不调用 Google/1Password，不上传图片或收藏清单。
- 无外部 JavaScript 依赖、无遥测、无自动更新源。ZIP 在本机内存中生成。
- 下载与使用素材请遵守原作者授权；收藏或下载不等于获得商业使用许可。

## 常见问题

**右下角没有按钮**：确认在 `https://visie.io/shortlists/数字` 的收藏详情页，不是收藏首页；确认脚本猫启用、脚本启用、获得 Visie 站点权限，随后刷新。

**提示没有收藏数据 / 跳转登录**：只在你平时用的 Chrome 重新登录 Visie，并确认该收藏能正常打开。不需要登录 PI 内置浏览器。

**HTTP 403 / 404**：该源图片可能已失效、没有权限或有防盗链限制。本版不会绕过限制；可检查导出的链接，或稍后重试。

**反复提示网络错误**：检查脚本猫对上述 CDN 域名的请求授权及网络连接。HTTP 429 和临时网络错误会限次等待重试。

**自动保存后找不到 ZIP**：查看 Chrome 的下载列表、多个文件下载授权、拦截提示和保存位置。脚本只能确认发起保存，不能确认操作系统已成功写入。浏览器静默拦截不一定能被脚本检测；请改用手动模式，必要时重新选择缺失图片。最近一包可以直接补存。

## 验证与维护

已根据 Visie 当前公开前端的收藏渲染逻辑和内嵌 JSON 结构编写；开发时无法进入用户的真实收藏，不要求用户迁移登录状态。真实账号 + 脚本猫扩展环境仍需安装后确认。

v1.1.0 已通过 JavaScript 语法检查、17 项核心测试（含 Python 独立解包/CRC 校验）及 32 项模拟浏览器交互检查，覆盖选图、筛选、分页、自动保存、手动补存、异常降级、停止续传及失败重试。基线还曾实际取得一张公开 CDN 原图（1,620,978 字节 JPEG）。模拟测试截获了保存动作，**未验证用户真实 Chrome + 脚本猫环境的文件落盘**。

开发测试命令（用户日常使用不需要）：

```sh
node --check visie-shortlist-downloader.user.js
node --test tests/core.test.cjs
```

核心测试还使用 Python 标准库独立校验 ZIP 解包和 CRC，不需要安装第三方包。
