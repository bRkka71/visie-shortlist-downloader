# Visie 收藏原图批量下载

一个浏览器用户脚本：在 [Visie](https://visie.io) 的收藏页里**按项目挑选图片**，按你定的规则**命名**，再**自动打包成 ZIP 下载原图**。

- 按项目勾选，也可以展开项目只挑其中几张；能按项目名、品牌、日期搜索
- 文件夹名和文件名可以自定义，比如 `品牌_日期_项目/项目_01.jpg`
- 记住下载过的图片，下次可以「只选未下载」
- 下载的是 Visie 提供的原图，不是缩略图；停止后能继续，失败的图片能单独重试
- 使用你浏览器里现有的 Visie 登录状态，不需要输入密码，也不上传任何数据

---

## 第一步：安装脚本猫

脚本猫（ScriptCat）是一个免费的浏览器扩展，用来运行用户脚本。官网：<https://scriptcat.org/zh-CN>

| 浏览器 | 安装地址 |
| --- | --- |
| Chrome | [Chrome 应用商店 · ScriptCat](https://chromewebstore.google.com/detail/scriptcat/ndcooeababalnlpkfedmmbbbgkljhpjf) |
| Edge | [Edge 外接程序 · ScriptCat](https://microsoftedge.microsoft.com/addons/detail/scriptcat/liilgpjgabokdklappibcjfablkpcekh) |
| Firefox | [Firefox 附加组件 · ScriptCat](https://addons.mozilla.org/zh-CN/firefox/addon/scriptcat/) |

1. 用你平时登录 Visie 的浏览器打开上面对应的链接，点 **添加至 Chrome**（或“获取”“添加到 Firefox”），再在弹窗里确认。
2. 装好后，点地址栏右边的拼图图标 🧩，把 **脚本猫** 固定到工具栏，方便以后打开。
3. **Chrome / Edge 需要多开一个权限**，否则脚本不会运行：
   - 打开 `chrome://extensions`（Edge 是 `edge://extensions`），找到脚本猫，点 **详情**。
   - 如果有 **允许运行用户脚本**（Allow User Scripts）开关，把它打开。
   - 如果没有这个开关，就打开页面右上角的 **开发者模式**。
   - 不同浏览器版本的叫法可能不一样。脚本猫首次打开时通常也会提示你怎么开。

> 已经装了 Tampermonkey（油猴）也可以用，安装方式和下面一样。

## 第二步：安装本脚本（三种方式任选一种）

### 方式一：点链接安装（推荐）

1. 在装了脚本猫的浏览器里打开这个地址：

   ```
   https://raw.githubusercontent.com/bRkka71/visie-shortlist-downloader/main/visie-shortlist-downloader.user.js
   ```

2. 脚本猫会弹出安装页面，显示脚本名「Visie 收藏原图批量下载」和需要的权限，点 **安装**。
3. 如果浏览器只是显示了一大段代码、没有弹出安装页，说明脚本猫没接管，改用方式二。

### 方式二：复制粘贴

1. 打开本仓库的 [visie-shortlist-downloader.user.js](visie-shortlist-downloader.user.js)，点右上角的 **复制**图标（Copy raw file），复制全部代码。
2. 点工具栏的脚本猫图标 → **管理面板**（或“脚本列表”）→ **＋ 新建脚本** → 普通脚本。
3. 在编辑器里按 `⌘A`（Windows 是 `Ctrl+A`）全选，删掉默认内容，粘贴刚才的代码。
4. 按 `⌘S`（`Ctrl+S`）保存。脚本列表里出现「Visie 收藏原图批量下载」并处于启用状态，就装好了。

> 一定要复制**全部内容**，包括开头 `// ==UserScript==` 到 `// ==/UserScript==` 的那几行，否则脚本不会生效。

### 方式三：下载文件再导入

1. 打开 [visie-shortlist-downloader.user.js](visie-shortlist-downloader.user.js)，点右上角的 **下载**图标（Download raw file），保存到电脑。
2. 打开脚本猫的 **管理面板**，把下载的 `.user.js` 文件**直接拖进管理面板页面**，在弹出的安装页点 **安装**。
3. 如果拖进去没有反应，就用文本编辑器打开这个文件，全选复制，再按方式二粘贴。

### 首次运行时的授权

第一次下载时，脚本猫可能会问是否允许脚本访问 `cdn.visie.io`（Visie 的图片服务器）。确认域名无误后选 **总是允许**，否则图片下不下来。

## 第三步：开始下载

1. 在装了脚本猫的浏览器里登录 Visie，打开任意一个收藏详情页（地址形如 `https://visie.io/shortlists/数字`）。
2. 点页面右下角的 **Visie 下载**，会弹出项目列表。默认一张都不选。
3. 挑选图片：
   - **点项目卡片**：选中或取消整个项目。
   - **点「选单张」**：展开这个项目的图片，只勾你要的几张。
   - **搜索框**：按项目名、品牌、日期筛选。筛选时已选的不会丢。
   - **选未下载**：只选还没下载过的图片。**隐藏已下载项目**：列表里只留新项目。
4. 在右侧设置命名（见下一节），确认预览没问题。
5. 点 **开始下载（N 张）**。脚本会自动分包保存 ZIP，默认每包最多 50 张。
6. Chrome 如果提示「此网站想下载多个文件」，点 **允许**。下载完成后，在浏览器的下载列表里找到 ZIP 解压即可。

下载过程中可以点 **停止**，之后点 **继续剩余** 接着下。失败的图片可以点 **重试失败**，只重下失败的那几张。

## 命名设置

右侧「命名方式」可以选预设，也可以自己拼：

| 预设 | 文件夹 | 文件名 |
| --- | --- | --- |
| 按项目分文件夹（推荐） | `001_品牌_项目` | `项目_01.jpg` |
| 品牌_日期_项目 | `品牌_2026-11-04_项目` | `品牌_项目_01.jpg` |
| 全部放一个文件夹 | 不分文件夹 | `品牌_项目_01.jpg` |
| 保留 Visie 原文件名 | `001_项目` | 原文件名 |

自定义方法：在「文件夹名」或「文件名」输入框里点一下光标位置，再点下方的字段按钮插入，例如 `{品牌}_{日期}_{项目}`。下面会实时预览前几张的命名结果。

可用字段：

| 字段 | 含义 |
| --- | --- |
| `{收藏}` | 收藏夹名称 |
| `{项目}` / `{完整标题}` | 项目名 / 项目完整标题 |
| `{品牌}` | 项目所属品牌（摄影师类条目为职业） |
| `{日期}` | 项目日期，如 2026-11-04 |
| `{项目序号}` / `{图片序号}` / `{总序号}` | 项目在收藏中的序号 / 图片在项目中的序号 / 图片在本次下载中的序号 |
| `{原文件名}` / `{尺寸}` / `{图片ID}` | Visie 原文件名 / 宽x高 / Visie 图片编号 |

- 文件夹名留空，所有图片放在同一层。
- 某个字段为空时会自动省略，不会留下多余的下划线。
- 名字重复时会自动加 `_2`、`_3`。
- 命名和下载设置会自动记住，下次打开不用重设。

## 更新到新版本

- **用方式一安装的**：重新打开第二步里的安装地址，脚本猫会提示更新，点 **更新** 即可。
- **用方式二或三安装的**：在脚本猫管理面板里编辑原来的「Visie 收藏原图批量下载」，全选后粘贴新版代码，保存。不要新建第二个，否则页面上会出现两个按钮。

更新后刷新 Visie 页面。版本号写在脚本开头的 `@version` 一行。

## 常见问题

**页面右下角没有「Visie 下载」按钮**
- 确认打开的是收藏**详情页**（`/shortlists/数字`），不是收藏列表页。
- 确认脚本猫和本脚本都是启用状态，Chrome / Edge 已打开「允许运行用户脚本」或开发者模式（见第一步）。
- 改完设置后刷新页面。

**提示读不到收藏数据，或跳转到登录页**
在这个浏览器里重新登录 Visie，确认收藏页能正常打开后再试。

**图片下载失败（HTTP 403 / 404 / 网络错误）**
- 检查是否允许了脚本访问 `cdn.visie.io`（见「首次运行时的授权」）。
- 可能是图片在 Visie 上已失效，或网络不稳定。稍后点 **重试失败**。

**下载完找不到 ZIP**
- 看浏览器的下载列表，以及地址栏是否出现「已阻止多个下载」的图标，点它选择允许。
- 如果经常被拦截，在右侧关掉「自动保存 ZIP」，改为每包手动点保存。
- 面板里的 **重存最近一包** 可以不重新下载、直接再保存一次最近一包。

**被标成「已下载」，但其实没保存成功**
脚本在发起保存时就会记录。若浏览器拦截了下载，点右侧 **清除本收藏的下载记录**，再重新下载。

**下载的是原图吗？**
是 Visie 收藏数据中提供的原始图片地址，不是网页上的缩略图。缩略图只用于选图窗口的预览。视频不会下载。

## 隐私与说明

- 只在 Visie 网站上运行，只有你点击后才读取收藏和下载图片。
- 只读取收藏，不会添加、删除或修改你的收藏。
- 使用浏览器里现有的登录状态，不读取密码，不导出 Cookie，不把图片或收藏清单上传到任何服务器。ZIP 在本机生成。
